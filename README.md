# StudyMate
StudyMate is a simple, user-friendly study task and deadline management web application built with HTML, CSS, and JavaScript. It helps students organize academic tasks by subject, deadline, and priority, while allowing them to track completed and pending tasks. The project also uses browser localStorage to save tasks between sessions.
## 📚 StudyMate — Study Task & Deadline Tracker

StudyMate is a simple web application designed to help students organize and manage their academic tasks, assignments, and deadlines in one place.

The application allows users to add study tasks along with the subject, deadline, and priority level. Users can mark tasks as completed, undo completed tasks, or delete tasks when they are no longer needed. A simple dashboard also displays the total number of tasks, completed tasks, and pending tasks.

## ✨ Features

* Add new study tasks
* Add subject and deadline information
* Set task priority as High, Medium, or Low
* Mark tasks as completed
* Undo completed tasks
* Delete tasks
* View total, completed, and pending tasks
* Save tasks using browser localStorage
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* **HTML** — Used to create the structure and content of the application
* **CSS** — Used for styling, layout, colours, buttons, cards, and responsive design
* **JavaScript** — Used to add functionality and interactivity
* **LocalStorage** — Used to store tasks locally in the user's browser

## 🎯 Purpose of the Project

The purpose of StudyMate is to provide students with a simple way to keep track of their academic responsibilities and avoid missing important tasks or deadlines.

This project was also created as a beginner-level web development project to understand the fundamentals of HTML, CSS, JavaScript, DOM manipulation, events, arrays, objects, functions, and browser localStorage.
